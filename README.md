## 💫 About me

Frontend developer with 5 years of React. I build data-heavy interfaces: dashboards,
large data grids, form engines and design systems, with a focus on performance,
accessibility (WCAG) and right-to-left support.

- 🔭 Building 16 live demo projects, each on its own subdomain with a public repo
- 🌱 Learning: Web Workers, DuckDB-WASM, WebGL
- 💬 Ask me about: React performance, TanStack Query/Table, Zod, design tokens
- 🌍 Languages: English, Persian
